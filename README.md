# Tema_1_RN

Rezolvarea unui sistem de 3 ecuatii liniare cu 3 necunoscute, fara numpy, folosind doar liste Python.

## Fisiere

- `enunt_tema_1.ipynb` - enuntul temei
- `rezolvare_tema_1.py` - rezolvarea temei (functiile din enunt)
- `system.txt` - sistemul de ecuatii citit de program

## Cum se ruleaza

1. Puneti `system.txt` in acelasi folder cu `rezolvare_tema_1.py`.
2. Ruleaza:

```
python rezolvare_tema_1.py
```
